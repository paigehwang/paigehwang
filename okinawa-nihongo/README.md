# 🌺 めんそーれ 日本語 — 오키나와 여행 회화 앱

2027년 1월 6일 오키나와 여행 전까지 12주 동안 일본어 회화를 연습하는 나만의 아이폰 앱입니다.

- **아이폰**: 사파리로 열어서 홈 화면에 추가 → 앱처럼 사용 (PWA)
- **AI 회화 상대**: 내 컴퓨터의 **Claude Code**(`claude -p`)가 직접 답합니다. API 키가 필요 없고 **Claude 구독 한도 안에서** 동작해요.

```
아이폰 (앱 화면)  ──Wi-Fi──▶  내 컴퓨터 server.js  ──▶  claude -p (Claude Code)
                  ◀──────────  일본어 대사 + 읽기 + 한국어 뜻 + 교정  ◀──
```

## 1. 처음 한 번만 준비

1. 컴퓨터에 **Node.js 18 이상**과 **Claude Code**가 설치돼 있고, 터미널에서 `claude`로 로그인돼 있어야 합니다.
   - 확인: 터미널에서 `claude -p "안녕"` 을 실행해서 답이 오면 준비 완료
2. 이 폴더를 컴퓨터에 받기
   ```bash
   git clone https://github.com/paigehwang/paigehwang.git
   cd paigehwang/okinawa-nihongo
   ```
   (외부 패키지가 없어서 `npm install`은 필요 없어요)

## 2. 매일 쓰는 법

1. 컴퓨터에서 서버 켜기
   ```bash
   npm start
   ```
   Mac에서는 `start.command`를 더블클릭해도 됩니다.
2. 터미널에 이렇게 주소가 뜹니다.
   ```
   아이폰(같은 Wi-Fi): http://192.168.0.12:8787/?k=1a2b3c4d
   ```
3. 아이폰을 **같은 Wi-Fi**에 연결하고 사파리에서 그 주소를 엽니다.
4. 공유 버튼 → **홈 화면에 추가**. 홈 화면 앱을 처음 열면 상단 ● 버튼 → 설정에서 **접속 키**(`?k=` 뒤 8자리)를 한 번 넣어 주세요.
   (홈 화면 앱은 사파리와 저장공간이 따로라서 한 번 더 입력해야 해요)

> 컴퓨터가 잠자기 상태가 되면 연결이 끊겨요. 공부하는 동안은 컴퓨터를 켜 두세요.
> 밖(카페·출퇴근길)에서도 쓰고 싶다면 컴퓨터와 아이폰에 **Tailscale**(무료)을 설치하고 터미널에 뜬 주소 대신 Tailscale IP(100.x.x.x)로 접속하면 됩니다.

## 5. 설정

| 환경변수 | 기본값 | 설명 |
|---|---|---|
| `NIHONGO_MODEL` | `sonnet` | 회화에 쓸 모델. 빠르고 한도를 아끼려면 `haiku`, 더 정교하게는 `opus` |
| `PORT` | `8787` | 서버 포트 |
| `NIHONGO_TOKEN` | 자동 생성 | 접속 키 (`.token` 파일에 저장됨) |
| `CLAUDE_BIN` | `claude` | claude 실행 파일 경로 |

예: `NIHONGO_MODEL=haiku npm start`

- 한 번 답하는 데 보통 5~10초 걸립니다 (Claude Code를 매번 실행하기 때문).
- 회화 기록과 진도는 아이폰 브라우저에 저장돼요. 장면마다 Claude 세션이 이어지기 때문에 앞에서 한 말을 기억합니다.
- Claude는 도구 없이(`--tools ""`) 빈 작업 폴더(`.claude-work/`)에서만 실행돼서 내 파일을 건드리지 않아요.
- 더 자연스러운 일본어 목소리: 아이폰 설정 → 손쉬운 사용 → 읽기 및 말하기 → 음성 → 일본어 → Kyoko(향상된 음질) 다운로드
